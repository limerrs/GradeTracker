# GradeTracker
Local grade tracking website that allows for the addition and substracting of class grades and their class averages, grouped by semesters.

# To Launch
Download GradesTracker_git folder -> In GraderTracker_git/dist, launch GradeTracker.exe.
This opens the python executable that runs grades.py and, subsequently, grade-tracker.thml, updated by the most recent changes made to grades.json.
